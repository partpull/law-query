# 法规查询（LawQuery）

Win11 桌面端的**法律法规按条检索**工具（Electron + mammoth，无需安装 Office）。

把 Word 法规放进程序根目录的「法规库」文件夹，启动时自动按条拆分建索引；输入关键字即可跨法规检索命中条文，结果**按法规分组、关键字标红**，点任意一条即在下方【法规原文】看到该条完整原文。

## v4.0 更新内容

### 1. 检索能力增强（多关键字 + 条号直达）

| 写法 | 含义 |
| --- | --- |
| `词A 词B` | **同时满足**：同一法条内必须同时出现这两个词 |
| `-词` | **排除**：含该词的法条不出现在结果里 |
| `第X条` | **条号直达**：按条号精确定位；其余词可用于匹配法规名 |
| 组合 | `中小企业 价格 -联合体`、`政府采购法 第二十一条` |

- 输入框下方新增语法提示，占位文字改为「输入关键字，或"法规名 第X条"」。
- 命中词**全部标红**（多处命中会合并重叠区间，不重复嵌套）。
- 条号直达时，法规名与检索词匹配的法规排在最前，自动选中，更接近"直接定位"的预期。
- 结果区统计行回显完整检索条件，例如：`检索条件「中小企业 价格 -联合体」· 范围 3/4 · 遍历 132 部法规 / 1908 条法条 · 命中 2 部 / 共 19 条`。
- 未命中时按模式给出不同提示（条号模式会提示确认该法规是否有这一条）。

### 2. 启动加速：拆条索引缓存

- 拆条结果缓存到**用户数据目录**（`law-index-cache.json`），**不写进「法规库」**，不污染法规文件夹。
- 按每个文件的**大小 + 修改时间**判断是否变化：未变直接复用，改了/新增才重新解析。
- 缓存带格式版本号，程序升级后自动失效重建；缓存文件损坏或写不进去都不影响正常使用。
- 左栏显示加载明细：`已读取 133 个 Word 文件（缓存命中 131，本次解析 2）· 0.9 秒`。
- 实测：连续两次加载同一法规库，第二次解析 0 个文件、耗时 **2ms**（对比首次 199ms）；法规库越大收益越明显。

### 3. 版本与打包

- 版本号升至 **4.0.0**，程序名 / 窗口标题为「**法规查询v4.0 by 6bu**」。
- 打包输出目录改为 `dist4`；构建脚本加 `--publish never`（避免因仓库配置了远端而自动尝试发布）。

## 使用方法

1. 把 `.docx` 法规放进与 `法规查询v4.0 by 6bu.exe` **同级**的「法规库」文件夹；
   建议按分类建二级文件夹（例如 `政府采购`、`招标投标`），程序会据此生成「查询范围」。
2. 启动程序：首次会解析全部 Word（生成缓存），之后启动直接命中缓存。
3. 左侧输入检索条件 → 勾选「查询范围」→ 点【遍历】。
4. 点击任一条结果，下方【法规原文】显示该条完整原文（固定 150px，右侧滚动条常显）。

> 新增或修改法规文件后，需**重新启动程序**才会重新加载（改动的文件会自动重新解析，未改动的走缓存）。

## 目录结构

```
main.js          主进程：窗口创建 + 法规库加载 IPC（含缓存路径）
preload.js       安全桥接（contextBridge）
lib/library.js   法规库扫描（二级文件夹）、.docx 解析、按条拆分、索引缓存
renderer/        界面：index.html / style.css / app.js
法规库/          你的法规 Word（.gitignore 已排除，不入库）
dist4/           打包产物：免安装版 + NSIS 安装包（.gitignore 已排除）
```

## 开发与打包

```bash
npm install        # 安装依赖（electron / electron-builder / mammoth）
npm start          # 开发运行
npm run dist       # 打包到 dist4：win-unpacked（免安装）+ NSIS 安装包
```

## 实现要点与边界

- **拆条规则**：只有**段首**的「第X条」才算新条开头；正文中的引用（如"出现第十五条第一款情形""依照第七条规定"）不会被误拆；兼容中文数字、阿拉伯数字（含全角）、字间空格（如 `第 三 条`）。
- **无条文结构的文件**（通知、函、清单等）整体存为 1 条「全文」，仍可被检索到。
- **关键字匹配**：忽略空格与换行、全半角统一、英文不区分大小写（标红仍按原文精确位置）。
- **格式支持**：仅 `.docx`；`.doc` 等会解析失败并在左栏提示文件名。
- 法规库为空或某个文件夹下没有 Word 时，对应查询范围不会出现。
